# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| Latest `main` and the most recent release | Yes |
| Older releases | No |

## Reporting A Vulnerability

**Do not open a public issue for security problems.**

Use GitHub **private vulnerability reporting** on this repository (Security
tab, then "Report a vulnerability"). Do not include real personal data in
reports.

This is a portfolio project maintained on a best-effort basis: reports are
triaged when possible and coordinated disclosure is appreciated, but no
acknowledgment or fix timeline is guaranteed.

## Scope Notes

- This is a community-maintained project, not a Microsoft product; do not
  report issues here to the Microsoft Security Response Center.
- The developer preview is not hardened for production or for processing real
  children's data; deployment hardening is the operator's responsibility.
- Never test vulnerabilities against systems or data you do not own.
