# Support

Wulo Academy is community-maintained, best-effort software.

- **Portfolio project:** published primarily for demonstration; issues are
  reviewed on a best-effort basis with no active development commitment.
- **Questions and bugs:** open a GitHub issue with reproduction steps,
  versions, and environment. Search existing issues first.
- **Security problems:** follow [SECURITY.md](SECURITY.md); never use public
  issues.
- **No warranty or SLA:** there is no guaranteed response time, no production
  support, and no compliance warranty. The developer preview is not intended
  for production deployments or real-child use.
- **Commercial or hosted Wulo services** are separate from this repository and
  are not supported here.
